# 片库解析源模块集

按 Forward 官方「模块合集」格式打包（`.fwd`）。

## 订阅链接（Forward）

在 Forward「设置 → 模块」粘贴：

```
https://raw.githubusercontent.com/whylkk/my-grok-skills/main/pianku-widgets/pianku.fwd
```

仓库目录：https://github.com/whylkk/my-grok-skills/tree/main/pianku-widgets
